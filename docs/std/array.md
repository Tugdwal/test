# std#array

`std#array` emulates a resizable array.

## Member functions

| Name | Description |
|---|---|
| *Special member functions* | |
| [`constructor`](array/constructor.md) | constructs a new array |
| *Capacity* | |
| [`size`](array/size.md) | returns the number of elements |
| *Element access* | |
| [`at`](array/at.md) | returns the specified element |
| [`back`](array/back.md) | returns the last element |
| [`front`](array/front.md) | returns the first element |
| [`set_at`](array/set_at.md) | replaces the specified element |
| [`set_back`](array/set_back.md) | replaces the last element |
| [`set_front`](array/set_front.md) | replaces the first element |
| *Modifiers* | |
| [`insert_at`](array/insert_at.md) | inserts a new element at the specified position |
| [`push_back`](array/push_back.md) | inserts a new element at the end |
| [`push_front`](array/push_front.md) | inserts a new element at the beginning |
| [`remove_at`](array/remove_at.md) | removes the specified element |
| [`pop_back`](array/pop_back.md) | removes the last element |
| [`pop_front`](array/pop_front.md) | removes the first element |
| [`take_at`](array/take_at.md) | removes and returns the specified element |
| [`take_back`](array/take_back.md) | removes and returns the last element |
| [`take_front`](array/take_front.md) | removes and returns the first element |
| *Operations* | |
| [`clear`](array/clear.md) | removes all the elements |
| [`fill`](array/fill.md) | assigns the specified value to all elements |
| [`resize`](array/resize.md) | changes the number of elements |

## Notes

`std#array` uses 1-based indexing.
